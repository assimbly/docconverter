# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 3.0.x   | Yes       |
| 2.x     | No        |
| 1.x     | No        |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Report privately using [GitHub Security Advisories](https://github.com/assimbly/docconverter/security/advisories/new), or email [raymondmeester@gmail.com](mailto:raymondmeester@gmail.com).

Include:

- The affected version
- A description of the issue
- Steps to reproduce, if you have them

You should receive an acknowledgement within a few days. If the report is confirmed, a fix will be prepared for a supported release before any public disclosure.
